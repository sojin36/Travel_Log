# ✈️ Travel Website

HTML과 CSS를 활용해 다양한 여행지를 소개하고 여행 기록을 담은 간단한 웹페이지입니다.

# 🌍 Pages
페이지	설명
index.html	메인 여행 페이지
index2.html	추가 여행 페이지
jeju.html	제주도 여행 페이지
International Travel.html	해외여행 소개 페이지
singapore/	싱가포르 관련 페이지

# 🛠️ Tech Stack
HTML5
CSS3

# 📸 Features
여행지별 웹페이지 구성
이미지와 텍스트를 활용한 여행지 소개
CSS를 활용한 레이아웃 및 디자인
국내외 다양한 여행지 기록

# 🎯 Goal
HTML과 CSS를 활용한 웹페이지 제작 연습
이미지와 텍스트를 활용한 콘텐츠 구성
웹페이지 레이아웃 및 스타일링 능력 향상

# 🌴 여행지의 매력을 웹페이지로 표현하며 HTML과 CSS를 연습한 프로젝트입니다.
